## Translated map

File: `assets/dust-map-en.png`

Created using the built-in image generation/editing tool in text-localization mode, using the original map as the edit target. All nine Russian labels were replaced and visually inspected. Original artwork and illustrative arrows were preserved as closely as possible; this remains the source site's illustrative map.

Prompt:

> Use case: text-localization. Edit target: the provided map image from the user's Arallith website. Translate ONLY every Russian label into English, using the same white condensed sans-serif style and positions. Exact replacements: Россия -> Russia; Казахстан -> Kazakhstan; Монголия -> Mongolia; Турция -> Turkey; Аральское море -> Aral Sea (two lines where needed); Иран -> Iran; Китай -> China; Пакистан -> Pakistan; Индия -> India. Preserve the entire underlying terrain, satellite-map geography exactly as illustrated, warm orange glowing arrows and their paths, white origin dot, lighting, dark teal/brown palette, 3:2 landscape composition, and all other pixels as closely as possible. Do not add, omit or duplicate any label or arrow. This is a text translation only, not a new map design. Save an image suitable as the replacement web asset.

Created with the built-in image tool using the original blue logo. The English tagline reads “RESTORING NATURE IN THE ARALKUM”. The translated logo is used in both the header and footer.

Prompt:

> Use case: text-localization. Edit target is the supplied ARALLITH blue logo. Replace only the Russian tagline at the bottom with exactly 'RESTORING NATURE IN THE ARALKUM'. Preserve the blue globe/hand/plant artwork, all stippled particles, the large ARALLITH wordmark, warm ivory background, proportions, and the original blue colors and positions. Use a single line of uppercase clean sans-serif English lettering matching the existing tagline weight and spacing, centered below the unchanged ARALLITH wordmark. No Russian text should remain. This is a precise localization for a website, not a redesigned logo. Landscape aspect ratio about 1.44:1.

## Editable charts and timeline

The original Russian distance chart is now `assets/dust-distance.svg`. Labels and values: Aral region 200 km; Europe 3,000 km; Arctic 5,000 km; Antarctica 13,000 km. The bar lengths use a common distance scale.

The original Russian dust-and-salt graphic is now `assets/dust-figures.svg`. Text: approximately 100 million tonnes enter the air annually, documented on four continents, with decade labels from the 1980s through the 2020s. The original illustrative bar heights are retained without inventing numerical decade data.

The original timeline image is now an accessible HTML table in `index.html`, with rows for 1960, 1987, 2005, 2014, and Today. Its English text can be selected, copied, and edited.

The original percentage-decline GIF contains numbers and dates rather than Russian words and is retained as `assets/aral-decline.gif`.
